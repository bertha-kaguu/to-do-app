# 📝 Professional To-Do App

A clean and responsive To-Do List web application built using HTML, CSS, and JavaScript.

## 🚀 Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Data saved using Local Storage
- Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
